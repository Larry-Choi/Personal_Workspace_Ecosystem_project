# Asterism

> v1.0

Asterism은 앱, 폴더, URL, 명령어를 우주 공간의 별처럼 배치하고 실행할 수 있는 공간형 데스크톱 런처입니다.

일반적인 런처가 검색창이나 리스트 중심이라면, Asterism은 자주 사용하는 작업 요소들을 시각적인 노드로 배치합니다. 각 노드는 하나의 앱, 폴더, 웹사이트, 명령어를 나타내며, 관련된 노드들을 연결해 하나의 작업 묶음으로 구성할 수 있습니다.

**자주 사용하는 작업 환경을 별자리처럼 배치하고, 필요한 순간 한 번에 실행하는 런처.**

## 제작 배경

개발, 문서 작성, 음악 재생, 게임 서버 관리처럼 반복적으로 사용하는 작업 흐름은 매번 비슷한 앱과 폴더, 웹사이트를 필요로 합니다.

예를 들어 개발 작업을 시작할 때는 VS Code, 터미널, GitHub, 프로젝트 폴더를 열고, 마인크래프트 서버 작업을 할 때는 서버 패널, 모드 폴더, Discord, 런처를 열게 됩니다.

이런 반복적인 작업 진입 과정을 더 시각적이고 직관적으로 관리하기 위해 Asterism을 제작했습니다.

## 주요 기능

- 앱, 폴더, URL, 명령어를 노드로 등록
- 우주 배경 위에 노드를 자유롭게 배치
- 관련 노드끼리 연결하여 작업 그룹 구성
- 노드 클릭으로 개별 실행
- 그룹 실행을 통한 여러 작업 요소 동시 실행
- 키보드 단축키 기반 빠른 선택
- 노드 위치 및 구성 저장
- 개인 작업 흐름에 맞춘 공간형 런처 UI

## 핵심 컨셉

Asterism이라는 단어는 별자리 또는 별무리를 의미합니다. 이 프로젝트에서는 작업 요소 하나하나를 "별"로 보고, 관련 있는 별들을 연결해 하나의 작업 환경을 구성합니다.

예시:

```text
Development
- VS Code
- Terminal
- GitHub
- Project Folder

Music
- Underdesk Music
- BGM Playlist Folder

Minecraft
- Server Panel
- Mods Folder
- Discord
- Prism Launcher
```

각 그룹은 사용자의 작업 습관에 맞춘 작은 실행 환경이 됩니다.

## 설계 의도

Asterism은 단순히 프로그램을 실행하는 런처가 아니라, 작업에 진입하는 과정을 시각화하는 도구입니다.

리스트나 검색 기반 런처는 빠르지만, 작업 흐름의 구조를 보여주지는 않습니다. Asterism은 공간 배치와 연결선을 통해 작업 요소 간 관계를 표현합니다.

설계 원칙은 다음과 같습니다.

- 자주 쓰는 앱과 경로를 한 화면에서 볼 수 있을 것
- 작업별 묶음을 직관적으로 구성할 수 있을 것
- 실행 흐름이 시각적으로 드러날 것
- 개인의 작업 습관을 반영할 수 있을 것
- 런처 자체가 무겁거나 복잡하지 않을 것

## 프로젝트에서 다룬 문제

- 공간형 노드 UI 구성
- 앱/폴더/URL/명령어 실행 처리
- 노드 간 연결 구조 표현
- 작업 그룹 실행 모델 설계
- 키보드 기반 탐색 UX
- 사용자 정의 런처 데이터 저장
- 개인 작업환경을 시각적 구조로 표현하는 UI 설계

## 개인 작업환경 생태계에서의 역할

Asterism은 개인 작업환경 생태계에서 **Command Layer** 역할을 담당합니다.

작업을 시작할 때 필요한 앱, 폴더, 웹사이트, 명령어를 빠르게 실행하고, 반복적인 작업 진입 과정을 단축합니다.
