# 개인 작업환경 생태계 구축

> v1.0

개인 작업환경 생태계 구축은 사용자의 실제 작업 습관에 맞춰 음악 재생, 앱 실행, 문서 작성 같은 반복적인 작업 흐름을 독립적인 로컬 데스크톱 앱으로 분리하고, 이를 하나의 생산성 환경으로 구성한 프로젝트입니다.

기존의 범용 생산성 도구에 작업 방식을 맞추는 대신, 직접 필요한 도구를 만들고 연결하는 방식으로 개인 작업환경을 구축했습니다.

## 프로젝트 목표

이 프로젝트의 목표는 거대한 올인원 생산성 앱을 만드는 것이 아닙니다.

대신 각 문제를 작고 명확한 앱으로 분리했습니다.

- 음악 재생 문제 -> Underdesk Music
- 작업 진입 문제 -> Asterism
- 문서 작성 문제 -> Underleaf

각 앱은 독립적으로 동작하지만, 전체적으로는 하나의 개인 작업환경을 구성합니다.

## 구성 앱

### Underdesk Music

YouTube BGM을 크롬 탭이 아닌 독립적인 데스크톱 앱에서 재생하기 위한 미니 음악 플레이어입니다. 작업 중 브라우저 탭에 방해받지 않고 배경음악을 관리하는 것을 목표로 합니다.

역할: **Ambient Layer**

### Asterism

앱, 폴더, URL, 명령어를 우주 공간의 별처럼 배치하고 실행할 수 있는 공간형 런처입니다. 반복적인 작업 진입 과정을 시각화하고, 작업별 실행 묶음을 구성할 수 있습니다.

역할: **Command Layer**

### Underleaf

문장을 블록 단위로 작성하고 재배열하면서, 오른쪽 패널에서 완성된 문서 형태를 실시간으로 확인하는 블록 기반 문서 편집기입니다. 문법보다 조작 중심의 구조적 글쓰기를 목표로 합니다.

역할: **Writing Layer**

## 전체 설계 관점

이 프로젝트는 세 가지 레이어로 구성됩니다.

```text
Ambient Layer  - Underdesk Music
Command Layer  - Asterism
Writing Layer  - Underleaf
```

### Ambient Layer

작업 중 필요한 배경음악 환경을 분리합니다. 음악이 브라우저 탭이나 메인 작업 흐름을 방해하지 않도록 합니다.

### Command Layer

자주 사용하는 앱, 폴더, 웹사이트, 명령어를 빠르게 실행합니다. 작업을 시작하기 위한 진입 비용을 줄입니다.

### Writing Layer

아이디어와 문서를 문장 단위로 구조화합니다. 글의 논리 흐름을 쉽게 재배열하고 결과물을 다양한 형식으로 내보냅니다.

## 왜 만들었는가

이 프로젝트는 "생산성 앱을 많이 쓰는 것"이 아니라, 내 작업 방식에 맞는 도구를 직접 만드는 것에서 출발했습니다.

기존 도구들은 강력하지만, 개인의 작은 불편함까지 정확히 해결해주지는 않습니다.

- 음악용 Chrome 탭이 Alt+Tab에 섞이는 문제
- 반복적으로 같은 앱과 폴더를 여는 문제
- 긴 글을 문장 단위로 재배열하기 어려운 문제

이런 문제들은 각각은 작지만, 매일 반복되면 작업 흐름을 방해합니다. 그래서 각 문제를 독립적인 데스크톱 앱으로 해결했습니다.

## 기술적 특징

- 로컬 우선 데스크톱 앱
- 개인 사용 패턴 기반 UX 설계
- 작고 독립적인 마이크로툴 구조
- Tauri 기반 경량 앱 개발
- React/TypeScript 기반 UI 구현
- 로컬 상태 저장
- 데스크톱 앱과 웹 UI의 결합
- 반복 작업을 줄이기 위한 기능 중심 설계

## 실행 방법

각 앱 폴더에서 의존성을 설치하고 실행합니다.

```powershell
cd Asterism
npm install
npm run tauri:dev
```

```powershell
cd UnderdeskMusic
npm install
npm run tauri:dev
```

```powershell
cd underleaf
npm install
npm run tauri
```

## 프로젝트 성격

이 프로젝트는 단순한 앱 모음이 아니라, 개인 작업환경을 직접 설계하고 구현한 실험입니다.

핵심은 다음과 같습니다.

**범용 도구에 사용자를 맞추는 대신, 사용자의 작업 습관을 기준으로 도구를 재구성한다.**

각 앱은 작은 문제를 해결하지만, 함께 사용될 때 하나의 개인 생산성 환경을 형성합니다.
