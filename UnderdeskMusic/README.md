# Underdesk Music

> v1.0

Underdesk Music은 YouTube BGM을 크롬 탭이 아닌 독립적인 데스크톱 앱에서 재생하기 위해 만든 미니 음악 플레이어입니다.

평소 작업하거나 공부할 때 YouTube에서 게임 BGM 커버, 피아노 커버, 작업용 음악을 자주 틀어두는데, 브라우저 탭으로 음악을 재생하면 Alt+Tab 전환이나 작업창 관리에서 불편함이 있었습니다. Underdesk Music은 이러한 불편함을 해결하기 위해 제작한 개인용 로컬 데스크톱 앱입니다.

목표는 단순합니다.

**크롬 탭을 열어두지 않고도, 작은 독립 창에서 YouTube 음악을 조용히 재생하는 것.**

## 제작 배경

작업 중에는 음악이 필요하지만, 음악을 재생하는 브라우저 탭이 작업 흐름을 방해하는 경우가 많았습니다. 특히 여러 창을 오가며 작업할 때 음악용 Chrome 창이 Alt+Tab 목록에 섞이는 점이 불편했습니다.

처음에는 Chrome 확장 프로그램을 고려했지만, 실제 문제는 "브라우저 안에서 음악을 컨트롤하는 것"이 아니라 "브라우저 밖으로 음악 플레이어를 분리하는 것"이었습니다. 그래서 독립 실행형 데스크톱 앱으로 방향을 잡았습니다.

## 주요 기능

- YouTube 영상 URL 기반 음악 재생
- YouTube 검색 및 결과 선택
- 플레이리스트 추가/삭제
- 재생/일시정지/다음 곡 컨트롤
- 현재 재생 중인 곡 표시
- 플레이리스트 import/export
- 작은 독립 창 형태의 UI
- 최소화 시 작업 흐름을 방해하지 않는 동작
- 로컬 저장 기반 플레이리스트 유지

## 설계 의도

Underdesk Music은 일반적인 음악 스트리밍 앱을 대체하려는 목적이 아닙니다. 핵심은 작업 중 방해가 되지 않는 개인용 BGM 플레이어입니다.

따라서 UI는 복잡한 음악 앱처럼 많은 기능을 제공하기보다, 다음 원칙에 맞춰 설계했습니다.

- 작업 중 눈에 거슬리지 않을 것
- 브라우저 탭과 분리될 것
- 반복적으로 듣는 BGM을 빠르게 재생할 수 있을 것
- 플레이리스트 관리가 단순할 것
- 개인용 로컬 툴로 안정적으로 동작할 것

## 프로젝트에서 다룬 문제

- YouTube iframe 기반 재생 제어
- 독립 데스크톱 앱에서 웹 기반 플레이어 구성
- 플레이리스트 상태 저장
- 최소화/복원 UX
- 작업 흐름을 방해하지 않는 작은 UI 설계
- 개인 사용 패턴에 맞춘 로컬 앱 제작

## 개인 작업환경 생태계에서의 역할

Underdesk Music은 개인 작업환경 생태계에서 **Ambient Layer** 역할을 담당합니다.

작업 중 배경음악을 독립적으로 관리하여, 브라우저나 메인 작업창과 음악 재생 환경을 분리합니다.

## 기술 스택
