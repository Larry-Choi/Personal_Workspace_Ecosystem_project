# Underleaf

> v1.0

Underleaf는 문장을 블록 단위로 작성하고 재배열하면서, 오른쪽 패널에서 완성된 문서 형태를 실시간으로 확인할 수 있는 블록 기반 문서 편집기입니다.

Overleaf처럼 왼쪽에서 구조를 작성하고 오른쪽에서 결과물을 확인하는 방식을 참고했지만, LaTeX나 Markdown 문법을 직접 작성하지 않아도 되도록 설계했습니다. 사용자는 문법 대신 문장 블록, 단락 블록, 제목 블록, 목록 블록을 조립해 문서를 구성합니다.

**문법을 쓰지 않고, 문장을 배치해서 문서를 만든다.**

## 제작 배경

긴 글을 작성할 때 가장 어려운 부분은 문장 자체보다 문장의 순서와 단락 구조를 정리하는 과정입니다.

일반적인 문서 편집기에서는 문장이 하나의 흐름으로 이어져 있기 때문에, 문장 단위로 순서를 바꾸거나 특정 구절을 분리해 다른 위치에 삽입하는 과정이 번거롭습니다. 반대로 Overleaf나 Markdown은 구조적인 문서 작성에 강하지만, 문법을 알아야 하고 편집 과정이 상대적으로 기술적입니다.

Underleaf는 이 둘 사이의 간극을 해결하기 위해 만들었습니다.

- 일반 문서 편집기보다 구조를 조작하기 쉬울 것
- Overleaf보다 문법 부담이 적을 것
- 문장을 독립적인 단위로 재배열할 수 있을 것
- 작성 화면과 결과 화면을 분리해 볼 수 있을 것

## 핵심 컨셉

Underleaf에서 왼쪽 편집 패널의 모든 문장은 줄 단위 블록으로 표시됩니다.

```text
이 문서는 Underleaf의 작동 방식을 설명한다.
Underleaf는 문장을 블록으로 취급한다.
사용자는 문장의 순서를 드래그로 바꿀 수 있다.
```

오른쪽 미리보기에서는 단락 구분 전까지 문장들이 자연스럽게 이어집니다.

```text
이 문서는 Underleaf의 작동 방식을 설명한다. Underleaf는 문장을 블록으로 취급한다. 사용자는 문장의 순서를 드래그로 바꿀 수 있다.
```

Paragraph Break 블록을 삽입하면 문단이 나뉩니다.

```text
이 문서는 Underleaf의 작동 방식을 설명한다. Underleaf는 문장을 블록으로 취급한다.

사용자는 문장의 순서를 드래그로 바꿀 수 있다.
```

즉, 왼쪽은 구조 편집 뷰, 오른쪽은 문서 결과 뷰입니다.

## Extract 기능

Underleaf의 핵심 기능 중 하나는 문장 내부의 일부 텍스트를 선택해 별도의 블록으로 추출하는 기능입니다.

예를 들어 다음 문장에서:

```text
Underleaf는 복잡한 문법 없이 구조적인 문서를 만들 수 있게 한다.
```

`복잡한 문법 없이`를 선택하고 Extract를 실행하면, 선택한 구절이 별도의 블록으로 분리됩니다.

이 기능은 문장 내부의 표현을 재배치하거나, 특정 구절을 다른 문장으로 옮기고 싶을 때 유용합니다.

Underleaf는 단순히 문장 전체를 이동하는 편집기가 아니라, 문장 내부의 구절까지 조작 가능한 구조적 편집기를 목표로 합니다.

## 설계 의도

Underleaf의 설계 원칙은 다음과 같습니다.

- 문장을 독립적인 편집 단위로 다룰 것
- 문서 구조는 문법이 아니라 블록으로 표현할 것
- 단락은 Paragraph Break 블록으로 명시적으로 나눌 것
- 왼쪽에서는 구조를 편집하고, 오른쪽에서는 결과물을 볼 수 있을 것
- 사용자가 문장 순서를 쉽게 바꿀 수 있을 것
- 작성 중인 글의 논리 흐름을 조립하듯 수정할 수 있을 것

## 개인 작업환경 생태계에서의 역할

Underleaf는 개인 작업환경 생태계에서 **Writing Layer** 역할을 담당합니다.

아이디어, 보고서, 기획서, 문서 초안처럼 구조를 계속 바꿔야 하는 글을 문장 단위로 편집하고, 결과물을 다양한 문서 형식으로 내보낼 수 있도록 지원합니다.
